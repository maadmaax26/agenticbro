# How to Enable Mention-only Mode for Agentic Bro Bot via @BotFather

## Steps in Telegram:

1. **Open Telegram** → search "**@BotFather**"
2. Find your bot conversation (should say "Agentic Bot Group")  
3. Send this command exactly as shown below ⬇️⬅️⚠️ IMPORTANT 🙄 DON'T ADD SPACES BEFORE THE GROUP ID NUMBER

## Command Format:
```bash
/setgroupmention enabled group:-1003751594817
```

NOT `/setmentionmode` — that command doesn't exist in BotFather! Use **/setgroupmention** with your group ID number.

## After Sending BotFather Will Reply With: ✅ "Done!"
