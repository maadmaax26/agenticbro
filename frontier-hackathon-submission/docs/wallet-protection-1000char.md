# Agentic Bro Wallet Protection

Wallet Protection decodes Solana transactions BEFORE you sign them — showing exactly what will happen in plain language with AI-powered risk scoring.

Paste any transaction and see every instruction broken down: token transfers, destination addresses, fees, and approvals. The 90-point risk engine flags wallet drainers (25pts), hidden Token-2022 fees (15pts), permanent delegate attacks (15pts), and malicious revocations (10pts).

The scanner detects System instructions, SPL Token transfers, Token-2022 extensions (transfer fees, permanent delegate, metadata pointer), Metaplex, Jupiter swaps, Raydium, and Orca instructions — all converted from raw blockchain data into human-readable steps.

Key protections: permanent delegate detection warns when someone retains freeze/burn rights over your tokens; hidden fee scanning reveals embedded Token-2022 transfer taxes up to 100%; approval analysis flags unlimited token allowances to unknown addresses; and drainer pattern recognition catches multi-step emptying sequences before they execute.

Powered by Helius RPC for real-time on-chain data and local AI inference for sub-2-second analysis. Works standalone at agenticbro.app and integrates via API for wallet developers.
