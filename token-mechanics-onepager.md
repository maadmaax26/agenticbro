# $AGNTCBRO Token Mechanics — Supply Sink Model

## The Core Mechanic

**Hold $100 in $AGNTCBRO → Unlock 50 scans per month**
**OR pay $1 per scan à la carte**

---

## Why This Works (The Supply Sink)

### Problem with pay-per-scan tokens:
User buys token → uses service → immediately sells → downward pressure → death spiral

### Our solution — the hold model:
User buys $100 in $AGNTCBRO → **must maintain hold** → scans unlocked → no sell pressure → structural demand floor

**Every new user = net buying pressure with zero corresponding sell velocity.**

## The Math

| Metric | Value |
|--------|-------|
| Hold requirement | $100 in $AGNTCBRO |
| Scans per month (held) | 50 |
| À la carte price | $1/scan |

**1,000 users holding $100 each = $100K in organic demand sitting in wallets, not on exchanges.**

**10,000 users = $1M in locked demand.**

## Why Users Choose Holding Over Paying

1. **2x value:** 50 scans at $1 each = $50. Hold $100, get $50 in scans monthly. Breakeven in 2 months.
2. **Price appreciation upside:** If $AGNTCBRO goes up, your hold gains value AND your scans stay unlocked.
3. **No recurring payment:** No credit card, no subscription — just hold the token.
4. **Self-custody:** Your keys, your tokens, your scans. Non-custodial by design.

## Downward Pressure Protection

| Scenario | Effect on Token |
|----------|----------------|
| User buys $100 to hold | ✅ Buy pressure, no sell |
| User drops below $100 | ⚠️ Scans paused — incentivizes rebuy |
| User sells entirely | ❌ Scans revoked — was never paying for service |
| New user onboarded | ✅ New $100 buy order, zero sell offset |
| Scan demand grows | ✅ More users = more holds = more locked supply |

## Supply Dynamics

- **Total Supply:** 1B $AGNTCBRO
- **Circulating:** Market-dependent
- **Locked in hold requirements:** Grows with user base
- **Net effect:** As user base grows, circulating supply shrinks → scarcity increases → price floor rises
